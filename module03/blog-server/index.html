A small blog served by a bare http.server — no framework, no build step.

Routes

HomeGET / Blog feedGET /blog Contact formPOST /contact Posts as JSONGET /api/posts Anything else404

Where the data lives

Posts and comments are written to data/posts.json next to main.py. The file is rewritten atomically on every change, so you can open it in an editor while the server runs.

Run it

$ python3 main.py
Serving on http://localhost:8001
